Paths, cuts and connectivity

Interactive notes for the graph theory unit of Discrete Mathematics. Trace paths and circuits, remove vertices and edges to watch a graph fall apart, and measure how strongly it holds together.

Paths

Let n be a nonnegative integer and let u, v be vertices of an undirected graph G. A path of length n from u to v is a sequence of n edges e₁, …, en such that e₁ joins x₀ = u and x₁, e₂ joins x₁ and x₂, and so on, until en joins xn−1 and xn = v.

In a simple graph there is only one edge between two adjacent vertices, so we write a path by its vertex sequence x₀, x₁, …, xn. The length is the number of edges, which is one less than the number of entries in the sequence. A single vertex is a path of length 0.

Two consecutive vertices in the sequence must be adjacent. Nothing else is required: a path may revisit vertices and even reuse edges.

Circuits and simple paths

A path is a circuit (also called a cycle) if it begins and ends at the same vertex, that is u = v, and has length greater than zero.

A path or circuit is simple if it does not contain the same edge more than once. In a simple graph, the shortest simple circuit has length 3: a circuit u, v, u uses the edge {u, v} twice.

Connectedness

An undirected graph is connected if there is a path between every pair of distinct vertices. Otherwise it is disconnected.

The maximal connected subgraphs of G are its connected components. Every vertex lies in exactly one component, and a graph is connected exactly when it has one component.

Theorem. There is a simple path between every pair of distinct vertices of a connected undirected graph.

The proof takes a shortest path from u to v. If it repeated a vertex, the part between the two visits could be cut out to give a shorter path. So a shortest path repeats no vertex and therefore no edge (Exercise 6).

Cut vertices and cut edges

Removing a vertex means deleting it together with all edges incident to it. Removing an edge leaves its endpoints in place.

  • A cut vertex (or articulation point) is a vertex whose removal produces a graph with more connected components than G.
  • A cut edge (or bridge) is an edge whose removal produces a graph with more connected components than G.

A connected graph without cut vertices is called nonseparable. Removing one cut edge always adds exactly one component. Removing a cut vertex can add many.

An edge is a cut edge exactly when it lies on no simple circuit (Exercise 7). That is why every edge of a tree is a cut edge.

Vertex cuts and vertex connectivity

A subset V′ ⊆ V is a vertex cut (or separating set) if G − V′ is disconnected. A cut vertex is a vertex cut with one element.

The vertex connectivity κ(G) of a noncomplete graph is the minimum number of vertices in a vertex cut.

  • A complete graph Kn has no vertex cut: whatever we delete, the rest is still complete. By convention κ(Kn) = n − 1, the number of deletions that leave a single vertex.
  • κ(G) = 0 exactly when G is disconnected or G = K₁.
  • G is k-connected if κ(G) ≥ k. A connected graph with at least 3 vertices is 2-connected exactly when it has no cut vertex.

Edge cuts and edge connectivity

A set of edges E′ is an edge cut if G − E′ is disconnected. A cut edge is an edge cut with one element.

The edge connectivity λ(G) is the minimum number of edges in an edge cut. We set λ(G) = 0 when G is disconnected or G = K₁. G is k-edge-connected if λ(G) ≥ k.

One edge cut is always available: delete all edges at a vertex of smallest degree. That vertex becomes isolated, so λ(G) ≤ δ(G), where δ(G) = minv∈V deg(v).

In network terms, κ(G) counts how many routers must fail, and λ(G) how many cables must fail, before some computers can no longer reach each other.

Whitney's inequality

Theorem (Whitney, 1932). For every graph G,

κ(G) ≤ λ(G) ≤ minv∈V deg(v).

The right-hand inequality was shown above. For the left-hand one, take a minimum edge cut and replace each of its edges by a well-chosen endpoint; the chosen vertices form a vertex cut that is no larger (Exercise 13).

Both inequalities can be strict. In the graph on the right, two copies of K₄ are joined through the vertex d.

The general lesson for networks: a design can survive any single cable failure and still have a single router whose failure splits it.

    Exercise 6. Shortest paths are simple

    Let u ≠ v be vertices of a graph and suppose there is a path from u to v. Prove that a path of minimum length from u to v repeats no vertex, and conclude that it is simple.

    Show solution

    Let x₀, x₁, …, xn be a path of minimum length n from u to v. Suppose xi = xj for some i < j. Then x₀, …, xi, xj+1, …, xn is still a path from u to v, of length n − (j − i) < n. This contradicts minimality.

    A repeated edge {x, y} would force its endpoints to appear twice, so a path without repeated vertices has no repeated edges. It is simple. ∎

    Exercise 7. Cut edges and circuits

    Prove that an edge e = {u, v} of a graph G is a cut edge if and only if e lies on no simple circuit of G.

    Show solution

    (⇒, by contrapositive) Suppose e lies on a simple circuit C. Removing e from C leaves a path from u to v in G − e. Any path that used e can be rerouted along it, so G − e has the same components as G. So e is not a cut edge.

    (⇐, by contrapositive) Suppose e is not a cut edge. Then u and v are still in the same component of G − e, so by Exercise 6 there is a path from v to u in G − e with no repeated vertex. Adding e at the start gives a simple circuit through e. ∎

    Exercise 8. Ends of a bridge

    Let e = {u, v} be a cut edge of a connected graph G. Prove that if deg(u) ≥ 2, then u is a cut vertex. Deduce that a connected graph with at least 3 vertices and a cut edge has a cut vertex.

    Show solution

    Since deg(u) ≥ 2, u has a neighbour w ≠ v. Suppose G − u were connected. Then it contains a path from w to v that avoids u, and in particular avoids e. Together with the edge {u, w} this gives a path from u to v in G − e, so e is not a cut edge, a contradiction. Hence G − u is disconnected and u is a cut vertex.

    If G has at least 3 vertices and is connected, u and v cannot both have degree 1 (otherwise {u, v} would be a whole component). So one endpoint has degree at least 2 and is a cut vertex. ∎

    Exercise 10. Edge connectivity and degree

    Prove that λ(G) ≤ δ(G) for every graph G with at least 2 vertices. Give an example where the inequality is strict.

    Show solution

    If G is disconnected, λ(G) = 0 ≤ δ(G). Otherwise let v have degree δ(G) and let E′ be the set of edges at v. In G − E′, the vertex v is isolated while at least one other vertex remains, so G − E′ is disconnected. Hence λ(G) ≤ |E′| = δ(G). ∎

    Strict example: the Whitney gap graph, with λ = 2 < 3 = δ. A simpler one: two triangles joined by one edge have λ = 1 < 2 = δ.

    Exercise 11. Build the gap yourself

    Using Edit graph, build a graph with κ(G) = 1, λ(G) = 2 and δ(G) = 3 that is different from the Whitney gap preset. Verify the three numbers in Part 4. Explain in one sentence why each number is correct.

    Show solution

    One answer: take two copies of K₄, on a, b, c, d and on e, f, g, h, and add a new vertex x joined to c, d, e and f.

    • κ = 1: removing x separates the two copies of K₄.
    • λ = 2: the edges x–c and x–d form an edge cut. No single edge is a cut edge, because every edge lies on a triangle (for example x, c, d, x).
    • δ = 3: a, b, g and h have degree 3, and every other vertex has degree 4.

    Exercise 12. Designing a reliable network

    Six servers must be linked so that the network stays connected after any two cables fail and after any two servers fail. In graph terms, λ(G) ≥ 3 and κ(G) ≥ 3.

    1. Show that at least 9 cables are needed.
    2. Give a design with exactly 9 cables and verify it in Part 4.
    Show solution

    (a) By Whitney, δ(G) ≥ λ(G) ≥ 3, so every server has at least 3 cables. By the handshaking theorem, 2|E| = Σ deg(v) ≥ 6 · 3 = 18, so |E| ≥ 9.

    (b) The complete bipartite graph K3,3 has 9 edges and κ = λ = 3. The triangular prism (two triangles a, b, c and d, e, f with edges a–d, b–e, c–f) also works.

    Exercise 13. Challenge: the left half of Whitney

    Prove that κ(G) ≤ λ(G) for every connected graph G with at least 2 vertices.

    Show solution

    Let F be an edge cut with |F| = λ(G). Since F is minimum, G − F has exactly two components S and T, and F is exactly the set of edges between them.

    Case 1. Every vertex of S is adjacent to every vertex of T. Then λ = |S||T| ≥ |S| + |T| − 1 = n − 1 ≥ κ(G), because κ(G) ≤ n − 1 always.

    Case 2. Some x ∈ S and y ∈ T are not adjacent. For each edge of F, put one endpoint into a set U: its endpoint in S, unless that endpoint is x, in which case its endpoint in T. Then |U| ≤ |F|, and x, y ∉ U (the endpoint in T of an edge at x is not y). Every path from x to y uses an edge of F, and the vertex of U chosen for that edge lies on the path. So U separates x from y, and κ(G) ≤ |U| ≤ λ(G). ∎

    Exercise 14. Challenge: not everything is a cut vertex

    Prove that every connected graph with at least 2 vertices has at least two vertices that are not cut vertices.

    Show solution

    Take a path P = x₀, x₁, …, xk with no repeated vertex and with k as large as possible; k ≥ 1 since G is connected with 2 or more vertices. We show x₀ is not a cut vertex; the same argument works for xk.

    Every neighbour of x₀ lies on P, otherwise P could be extended. Let w be any vertex other than x₀. Since G is connected, follow a shortest path from w to the set {x₁, …, xk}. It cannot pass through x₀: the vertex just before x₀ would be a neighbour of x₀, hence already in {x₁, …, xk}, and the path would have stopped there. So every vertex reaches x₁, …, xk without using x₀, and these are joined to each other along P. Hence G − x₀ is connected. ∎
