การเข้ารหัสแบบดั้งเดิม (Classical Ciphers)

เข้าใจการเข้ารหัสแบบคลาสสิก (Shift, Affine) ที่ใช้เลขคณิตมอดุลาร์แปลงตัวอักษรเป็นตัวเลขแล้วเข้า/ถอดรหัส

นิยาม

วิธีการแปลงข้อความปกติ (Plaintext) ให้กลายเป็นข้อความลับ (Ciphertext) โดยใช้มือหรืออุปกรณ์กลไกง่าย ๆ ในอดีต ก่อนที่จะมีคอมพิวเตอร์และระบบดิจิทัลเข้ามาช่วยคำนวณทางคณิตศาสตร์ที่ซับซ้อน

สูตร

Shift: E(p) = (p + b) mod 26  ·  Affine: E(p) = (ap + b) mod 26

ให้ตัวอักษรแต่ละตัวถูกแทนด้วยจำนวนเต็ม p โดย A = 0, B = 1, …, Z = 25 และให้ a, b ∈ ℤ เป็นกุญแจ

ฟังก์ชันเข้ารหัสด้านบนนิยามไว้สองแบบ คือแบบเลื่อน (Shift) ที่บวกกุญแจ b เข้าไป และแบบอัฟฟีน (Affine) ที่คูณด้วย a ก่อนแล้วจึงบวก b

โดยแบบอัฟฟีนต้องมีเงื่อนไข gcd(a, 26) = 1 เพื่อให้ a มีตัวผกผันมอดุลาร์ a−1 และถอดรหัสกลับได้ด้วย D(c) = a−1(c − b) mod 26
