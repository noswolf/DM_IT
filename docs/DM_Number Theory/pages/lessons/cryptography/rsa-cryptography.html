การเข้ารหัส RSA (RSA Cryptography) — Capstone

เห็นภาพรวมว่า Number Theory ที่เรียนมาทั้งหมดประกอบกันเป็นระบบเข้ารหัส RSA ได้จริง

นิยาม

ระบบการเข้ารหัสข้อมูลแบบอสมมาตร (Asymmetric Encryption) ที่ใช้กุญแจสองดอกคู่กัน คือกุญแจสาธารณะสำหรับเข้ารหัสและกุญแจส่วนตัวสำหรับถอดรหัส

สูตร

c = me mod n  ·  m = cd mod n

ให้ p, q เป็นจำนวนเฉพาะที่ต่างกัน กำหนด n = pq และ φ(n) = (p−1)(q−1) จากนั้นเลือก e ที่ gcd(e, φ(n)) = 1 แล้วหา d ที่เป็นตัวผกผันมอดุลาร์ของ e คือ ed ≡ 1 (mod φ(n))

เราเข้ารหัสข้อความ m ให้เป็นข้อความลับ c และถอดรหัสกลับ ด้วยการยกกำลังมอดุลาร์ ตามสูตรด้านบน

โดย (n, e) คือกุญแจสาธารณะที่เผยแพร่ให้ใครก็ได้ ส่วน (n, d) คือกุญแจส่วนตัวที่ต้องเก็บเป็นความลับ — ความปลอดภัยของระบบมาจากการที่แยกตัวประกอบของ n เพื่อหา φ(n) นั้นทำได้ยากมากเมื่อ n มีขนาดใหญ่
