การแทนจำนวนเต็ม (Integer Representations)

เข้าใจการแทนจำนวนในฐานต่าง ๆ (2, 8, 16) และแปลงเลขไปมาระหว่างฐานด้วยอัลกอริทึมหารซ้ำ

นิยาม

วิธีการจัดเก็บและแสดงค่าจำนวนเต็มในระบบเลขฐานต่าง ๆ เช่น ฐาน 2 ฐาน 8 และฐาน 16 โดยแปลงจากฐาน 10 ด้วยการหารซ้ำด้วยฐานที่ต้องการ แล้วเก็บเศษในแต่ละรอบ

สูตร

n ÷ b = q0 เศษ a0,  q0 ÷ b = q1 เศษ a1, ...

ให้ b ∈ ℤ และ b > 1 และให้ n เป็นจำนวนเต็มบวก

เราสามารถแปลงจำนวนเต็มฐาน 10 ไปเป็นฐาน b ได้โดยหาร n ด้วย b ซ้ำ ๆ แล้วเก็บเศษที่ได้ในแต่ละรอบ

n ÷ b = q0 เศษ a0, q0 ÷ b = q1 เศษ a1, ...

เมื่อหารจนผลหารเป็น 0 แล้ว ให้นำเศษที่ได้มาอ่านจากรอบสุดท้ายย้อนกลับไปยังรอบแรก เพื่อได้คำตอบในฐาน b
