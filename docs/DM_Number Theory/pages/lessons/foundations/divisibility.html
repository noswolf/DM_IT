การหารลงตัว (Divisibility)

เข้าใจว่า a | b หมายถึงอะไร และเห็น pattern ของตัวหารผ่านภาพ

นิยาม

การที่จำนวนเต็มจำนวนหนึ่งหารด้วยจำนวนเต็มอีกจำนวนหนึ่งที่ไม่ใช่ 0 ได้ผลลัพธ์เป็นจำนวนเต็มพอดีโดยไม่มีเศษเหลือ

สูตร

a | b ⇔ b = ac สำหรับบางจำนวนเต็ม c

ให้ a, b ∈ ℤ และ a ≠ 0

เรากล่าวว่า a หาร b ลงตัว เขียนแทนด้วย a | b ก็ต่อเมื่อมีจำนวนเต็ม c ที่ทำให้ b = ac ตามสูตรด้านบน

หรือกล่าวได้ว่า b เป็นผลคูณของ a กับจำนวนเต็มบางจำนวน (c) จึงหารแล้วไม่มีเศษเหลือ
