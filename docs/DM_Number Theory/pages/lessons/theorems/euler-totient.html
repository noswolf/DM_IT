ฟังก์ชันออยเลอร์ (Euler's Totient Function φ(n))

เข้าใจ φ(n) เป็น "จำนวนตัวเลขที่ coprime กับ n" ผ่านการนับจริงบนภาพ ก่อนเจอสูตร

นิยาม

ฟังก์ชันในทางทฤษฎีจำนวนที่ใช้นับจำนวนเต็มบวก m ทั้งหมดที่น้อยกว่าหรือเท่ากับ n ซึ่งเป็นจำนวนเฉพาะสัมพัทธ์ (coprime หรือ relatively prime) กับ n (กล่าวคือ ห.ร.ม. ของ m และ n มีค่าเท่ากับ 1 หรือ gcd(m, n) = 1)

สูตร

φ(n) = จำนวนสมาชิกของ { k ∈ ℤ : 1 ≤ k ≤ n และ gcd(k, n) = 1 }

ให้ n เป็นจำนวนเต็มบวก

ฟังก์ชันออยเลอร์ φ(n) นิยามให้เป็นขนาดของเซตด้านบน คือนับดูว่าในช่วง 1 ถึง n มีจำนวนเต็มกี่ตัวที่ gcd(k, n) = 1

หรือกล่าวได้ว่า φ(n) คือจำนวนของจำนวนเต็มตั้งแต่ 1 ถึง n ที่เป็นจำนวนเฉพาะสัมพัทธ์กับ n

EULER'S TOTIENT — นับจำนวนที่ COPRIME กับ N

เจอแล้ว 0 ตัว(เลื่อนไปข้างหน้าเพื่อดูเส้นทาง gcd)
