สมภาค (Congruence)

จำนวนสองจำนวนอยู่ “บ้าน” เดียวกัน เมื่อเหลือเศษเท่ากันเมื่อหารด้วย n

นิยาม

การที่จำนวนเต็มสองจำนวนหารด้วยจำนวนเต็มบวกเดียวกันแล้วเหลือเศษเท่ากัน

สูตร

a ≡ b (mod n)  ⟺  n | (a − b)

ให้ a, b ∈ ℤ และ n เป็นจำนวนเต็มบวก

เรากล่าวว่า a และ b เป็น congruent modulo n ก็ต่อเมื่อ n หารผลต่าง (a − b) ลงตัว

a = b + kn  สำหรับบางจำนวนเต็ม k

หรือกล่าวได้ว่า a และ b เหลือเศษเท่ากันเมื่อหารด้วย n

Congruence — เลขบ้านเดียวกัน

จัดเลข 0–30 ลงตามเศษที่ได้จากการหารด้วย mod n

กด ▶ เพื่อดูการเติมเลขตามลำดับเศษ mod n ทีละตัว

เลือกเลข 2 ตัวจากช่องใดก็ได้เพื่อตรวจสอบว่า congruent กันไหม

Execution Monitor

เลขที่อยู่ในบ้านเดียวกันมีเศษเหลือเท่ากัน จึงเป็นสมภาคกัน modulo n

4 บ้านตามเศษ 0–3

ตัวเลขแต่ละตัวจะอยู่ในบ้านเดียว และตัวเลขในบ้านเดียวกันจะสมภาคกัน modulo 4
