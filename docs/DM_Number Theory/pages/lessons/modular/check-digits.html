เลขตรวจสอบ (Check Digits)

เข้าใจว่าเลขตรวจสอบท้ายบาร์โค้ด (UPC) ใช้เลขคณิตมอดุลาร์ตรวจจับข้อผิดพลาดจากการพิมพ์เลขผิดได้อย่างไร

นิยาม

เลขตรวจสอบ (Check Digit) คือ ตัวเลขหนึ่งหลัก (หรือตัวอักษร) ที่ถูกคำนวณขึ้นมาจากชุดตัวเลขหลักอื่น ๆ ก่อนหน้า โดยมีวัตถุประสงค์เพื่อใช้ตรวจสอบความถูกต้องของข้อมูล และป้องกันความผิดพลาดที่อาจเกิดขึ้นจากการคีย์ข้อมูลผิด การสลับตำแหน่งตัวเลข หรือการส่งผ่านข้อมูลในระบบคอมพิวเตอร์

สูตร

3·(d1+d3+…+d11) + (d2+d4+…+d10) + check ≡ 0 (mod 10)

ให้ d1d2…dk เป็นชุดตัวเลข โดยที่ k−1 หลักแรกคือหลักข้อมูล และหลักสุดท้าย dk คือหลักตรวจสอบ พร้อมด้วยน้ำหนักประจำหลัก w1, …, wk และมอดุลัส n

เรานิยาม เลขตรวจสอบ ให้เป็นหลักที่เลือกมาเพื่อทำให้ผลรวมถ่วงน้ำหนักของทุกหลักสอดคล้องกับสมภาค

w1d1 + w2d2 + … + wkdk ≡ 0 (mod n)

โดยระบบ UPC ใช้ w = (3, 1, 3, 1, …) กับ n = 10 ส่วน ISBN-10 ใช้ w = (10, 9, …, 2, 1) กับ n = 11 (จึงอาจได้หลักตรวจสอบเป็น X แทนค่า 10) — ถ้าสมภาคนี้ไม่เป็นจริง แสดงว่าชุดตัวเลขนั้นผิด

สร้างชุดตัวเลขของคุณเอง

กำหนดเลขหลักข้อมูลได้ตามต้องการ หลักสุดท้าย (Check Digit) จะคำนวณได้จากเลขหลักข้างหน้าโดยอัตโนมัติ
