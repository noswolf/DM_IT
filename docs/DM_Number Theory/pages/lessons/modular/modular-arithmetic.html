เลขคณิตมอดุลาร์ (Modular Arithmetic)

มองเลข mod n เป็น “นาฬิกา” ที่วนซ้ำ แทนที่จะเป็นแค่เศษจากการหาร

นิยาม

ระบบการคำนวณทางคณิตศาสตร์ที่เกี่ยวข้องกับเศษเหลือจากการหารจำนวนเต็มด้วยจำนวนคงที่จำนวนหนึ่ง ซึ่งเรียกว่า มอดุลัส (Modulus)

สูตร

a mod d = a − (floor(a/d) × d)

ให้ a ∈ ℤ และ d เป็นจำนวนเต็มบวก

ตามขั้นตอนวิธีการหาร จะมีจำนวนเต็ม q และ r เพียงชุดเดียวที่ทำให้

a = dq + r โดยที่ 0 ≤ r < d

เรานิยามให้ a mod d คือเศษเหลือ r ซึ่งคำนวณได้จากสูตรด้านบน

Modular Arithmetic — นาฬิกา mod d
