ตะแกรงเอราทอสเทนีส (Sieve of Eratosthenes)

เข้าใจ algorithm การ “กรอง” composite numbers ออกอย่างเป็นระบบ

นิยาม

ขั้นตอนวิธีโบราณที่ใช้ค้นหาจำนวนเฉพาะทั้งหมดที่มีค่าน้อยกว่าหรือเท่ากับจำนวนเต็ม n ที่กำหนด

สูตร

C = { k·p : p เป็นจำนวนเฉพาะ, p ≤ √n, k ≥ 2, k·p ≤ n }

ให้ n ∈ ℤ, n ≥ 2 และให้ S = { 2, 3, …, n }

เริ่มจากเซต S ซึ่งประกอบด้วยจำนวนเต็มตั้งแต่ 2 ถึง n จากนั้นพิจารณาจำนวนเฉพาะแต่ละตัวเริ่มไล่ตั้งแต่ 2 ที่ไม่เกิน √n แล้วตัดตัวที่จำนวนเฉพาะนั้น ๆ หารได้ออกไป เช่น 4, 6, 8, ... เพราะจำนวนเหล่านี้หารด้วย 2 ลงตัว จึงไม่ใช่จำนวนเฉพาะ เมื่อตัดของ 2 หมดแล้ว ก็ไปดูที่จำนวนเฉพาะต่อไปคือ 3 ทำแบบนี้เรื่อย ๆ จนถึงจำนวนเฉพาะตัวสุดท้ายที่ไม่เกิน √n ตัวเลขทั้งหมดที่ถูกตัดออกนี้รวมเรียกว่าเซต C

เมื่อคัดเลขใน C ออกครบแล้ว ตัวเลขที่ยังเหลืออยู่ใน S คือจำนวนเฉพาะทั้งหมดที่ไม่เกิน n วิธีคัดจำนวนประกอบออกทีละชุดเช่นนี้คือหลักการของตะแกรงเอราทอสเทนีส
